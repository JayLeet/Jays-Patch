# Credits

Jay's Patch is an unofficial server-side extension for **Sybillian's Blood on
the Clocktower Minecraft modpack**. Sybillian's work is the foundation this
package builds on.

## Sybillian And The Base Modpack

- **Sybillian** created the Blood on the Clocktower Minecraft modpack, its core
  datapack systems, menus, game infrastructure, and original base world.
- Jay's Patch targets **Sybillian's Blood on the Clocktower 1.5.4** for
  **Minecraft Java Edition 1.21.10**.
- This public package includes a modified copy of Sybillian's base world and
  Sybillian's `ct_biome` datapack. Jay's Patch does not claim ownership of
  either upstream work.
- The 138 role-icon textures bundled in the Jay's Patch resource-pack overlay
  are sourced byte-for-byte from the role textures distributed with
  Sybillian's modpack. Their original creator credits remain with Sybillian's
  credited community contributors.
