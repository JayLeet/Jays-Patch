## Current 1.9 beta clarifications

- Draft Buffet gives every legal nonempty character type equal odds for each
  card, then uses the accepted `4/2/1` archetype tickets. It has no general
  recycling mode; only an exact hand shortfall for a still-required type can
  reuse eligible earlier direct discards. Expanded live Draft QA is complete.
- Every Storyteller may use `Assign Demon Tonight` during any night. Choosing
  Lil' Monsta continues to the supported direct-Minion choice. Wraith score
  `325` is included in the generator-owned Grimoire reveal dispatcher.
- Before Boomdandy execution commits, the initiating Storyteller chooses the
  unique TNT pyre followed by Final Three or Sybillian's normal execution and
  death so the game continues. `Decide Later` commits neither path.
- Organ Grinder remains in trusted compatibility metadata so old state can be
  displayed, but it is excluded from setup, Draft, Greedy, and live character
  selection because Sybillian 1.5.4 does not support it.

These current rules supersede any shorter historical wording retained in the
large ownership rows below.

## Script Selection Transaction

TB, SNV, BMR, and custom JSON imports all rebuild the complete Sybillian
`ct:script` state through `setup/import/commit*`. This includes role categories,
night order, reminders, `current_script`, normalized name/author metadata, and the
generated Script item. Role enablement remains separate, so choosing a setup-room
script still leaves every wall role disabled until the Storyteller selects it.

Opening or cancelling the Custom Script dialog does not mutate the current setup.
Validation failures restore every backed-up `ct:script` field and regenerate the
previous Script item before temporary import state is removed.

## Storyteller's Passage State

Passage snapshots one numeric per-player voice-zone ID when it opens. The shared
zone detector mirrors every Sybillian voice marker except Town Square and detects
the Storyteller Den directly, without waiting for Sybillian's `den` tag. Starting
inside a valid zone still requires leaving it before that same zone can close
Passage during the day. At night, Passage can only open inside a player house;
leaving that starting house immediately teleports the still-spectating
Storyteller to the den, clears stale `in_house`, and only then restores the saved
mode and hotbar. Phase changes, Storyteller-role loss, and item-disable cleanup
request a safe close through the same two-block body-space guard instead of
restoring a player inside a wall. If night ends while Passage is open, it closes
safely before `night_exit` restores the true pre-night gamemode.
