## Inference

- Jay's report is more likely explained by intentional category weighting plus the proven hidden-path over-weighting than by a failure of Minecraft's random command.
- A two-dimensional type-plus-archetype lottery can create visibly mixed offers without traversing scripts or alphabetized character lists.
- Soft diversity weighting can discourage repetitive menus without making the system predictable. Hard guarantees such as three different types would create recognizable patterns and remove legal combinations from the lottery.
- Preselecting a setup-defining path can prevent incompatible ordinary choices, but Minions must be retired from player offers rather than deleted from the Storyteller's full catalog. Lord of Typhon and Kazali still require Storyteller access to those characters after ordinary Minion offers are gone.
- Allowing Legion to replace already completed choices can support a late Legion selection, but it changes those earlier choices into provisional assignments and requires rollback, hidden-identity cleanup, and final setup validation. The conversion stays private before game start and is revealed only through the final presented role during normal role reveal.
- Allowing a normal route to use the special-looking Demon flow for an actual Lunatic prevents the player from proving that a displayed Kazali, Legion, or Lord of Typhon came from the real 10% route. The generator must therefore derive setup from trusted actual route state rather than the displayed character.
- Atheist cannot be the only member of a probability-bearing archetype. Route class is separate metadata, so its dominant player-facing mechanic shares Public action, confirmation, and alternate victory with ordinary Townsfolk. A separate Storyteller-selected `Atheist Draft` guarantees the only route in which real Atheist is possible.
- Hidden identity and topology should be independent dimensions. A normal actual setup can still present Atheist or a special Demon as a Drunk/Lunatic mask, while a real special setup can still contain other legal hidden Outsiders elsewhere. A real character is not shown as a different ordinary character unless an approved hidden-character rule supplies that presentation.
- Making displayed types exactly equal as well as actual types would require the generator to compensate later visible cards for hidden masks. That would couple hidden identity to later offers, weaken independent per-card type rolls, and create another possible side channel about an earlier hidden result.
- Summoner and Lil' Monsta require their accepted early topology guards rather than joining either `Atheist Draft` or the random Demon-special route. Summoner is a Minion with no Drunk/Lunatic presentation counterpart; Lil' Monsta uses its accepted game-level active marker and nested direct-Minion draft rather than becoming a player's recorded role.
- Real and fake special-looking outcomes must have the same player-visible timing and UI. Otherwise a Storyteller setup pause for a real topology, but not a hidden fake, would leak the actual result.
- A real Lil' Monsta selection cannot use the ordinary Demon-finalization path because Lil' Monsta is not a player. The chosen player needs a nested direct-Minion 3/2/1 draft, which supplies the extra Minion created by Lil' Monsta setup.
- A separate active-state marker without matching private script metadata would leave the Storyteller without Lil' Monsta's normal night-order and reminder surfaces. Assigning player role `132` merely to make Sybillian detect it would instead mislabel the accepted direct-Minion player as Lil' Monsta.
- Lil' Monsta is excluded from Lunatic masks under the accepted nested-redraft contract. A real Lil' Monsta visibly starts the Minion redraft, while an actual Lunatic must continue believing they are a Demon; either behavior would reveal or break the hidden identity.
- Choosing the special route's Outsider target before the first player drafts removes the real-versus-fake Kazali timing difference entirely. The target becomes a legality input for building the draft rather than a reaction to a player's selection.
- The pre-draft Outsider target must constrain which real special characters and Legion totals remain eligible. If a normal-route hidden Lunatic/Hermit-Lunatic uses the matching special-looking presentation, any cover-only special target must be ignored and ordinary topology retained; otherwise a displayed mask would incorrectly alter setup.
- When Summoner creates Lil' Monsta, the selected player becomes an evil Minion rather than a player named Lil' Monsta. The live editor therefore needs a Minion-catalog branch for that target plus separate state recording that Lil' Monsta is in play.
- A plain normal route must exclude real setup-changing special results; otherwise it could create one without the pre-draft guards that make its topology legal. This does not exclude special-looking Lunatic/Hermit-Lunatic masks, because their actual characters remain ordinary hidden Outsiders and do not activate the displayed setup.
- A binary normal-versus-special coin flip would severely overweight the small special pool. The accepted fixed 10% game-level chance deliberately keeps the guaranteed-real route uncommon without deriving it from an accidental 50/50 split or an unrelated all-character ratio.
- The earlier player-count-aware special-route direction conflicts with the accepted type-first model. A roster-size curve calculated from all 138 characters would mix character categories even though the setup has one Demon slot and the offer generator now rolls type first. A fixed reduced share is easier to explain and matches the relevant `3 / 19` Demon mass.
- Showing a hidden fake Atheist inside an ordinary three-card hand while showing a real Atheist alone would prove that the ordinary-hand Atheist is Drunk or Hermit-Drunk. Every perceived Atheist therefore needs the same forced one-card presentation regardless of whether the Storyteller selected real `Atheist Draft` or a non-Atheist route generated a hidden fake.
- A non-Atheist fake-Athiest route is simply ineligible while the current setup has zero Outsider slots. If a selected setup modifier later increases the target above zero while a future drafter remains, the route becomes eligible at that first legal transition; it never creates an Outsider slot itself.
- Rolling fake Atheist once per eligible game avoids compounding across players, cards, and later setup modifiers. A 10% game-level roll means roughly one fake Atheist per ten eligible non-Atheist games and can be capped at one result per game.
- Discarding should retire characters, not type or archetype buckets. Rerolling both dimensions for every fresh card preserves the accepted arbitrary combination/order contract and prevents a player from deliberately exhausting a whole archetype.
- If every remaining actual slot is an Outsider, mixed perceived types create a retrospective hidden-role proof: later face-up-only rounds reveal that earlier perceived Townsfolk or Demons had to be Drunk/Lunatic variants. Freezing the entire turn to direct face-up Outsiders removes that transition and protects prior hidden identities.
- The forced face-up Outsider window should be recomputed before each new player's turn, not during a discard sequence. A selected setup modifier may enter or leave the window for later players, but one player's 3/2/1 presentation remains internally consistent.

## Current setup-defining contract

- Before Draft begins, the Storyteller privately chooses `Normal Draft` or `Atheist Draft`.
- `Normal Draft` performs one game-level route roll: 90% ordinary and 10% random Demon-special across 5-15 players. A real Atheist is impossible in either result.
- Winning the 10% Demon-special roll guarantees a real Kazali, Legion, or Lord of Typhon topology. The special route never converts into a hidden fake.
- `Atheist Draft` reserves one player whose only perceived selection and trusted actual identity are Atheist. This route guarantees that real Atheist is in play.
- A plain ordinary offer excludes Atheist, Kazali, Legion, and Lord of Typhon as real characters. It may still display a forced Atheist whose actual identity is Drunk/Hermit-Drunk, or a special Demon whose actual identity is Lunatic/Hermit-Lunatic, but only through the same player-visible flow used by the corresponding real route—not beside ordinary cards. Summoner and Lil' Monsta likewise require their controlled topology paths rather than appearing unguarded; Riot remains available normally.
- In the `Normal Draft` ordinary-versus-Demon-special roll, the ordinary route has 90% game-level weight and the Demon-special route has 10%. This probability does not change with player count.
- When a special path is rolled, the Storyteller chooses its route-level Outsider target before the first private player offer. Draft uses that count to filter incompatible real special characters. If Legion is later selected, Legion may replace that baseline target under the rule below.
- The random Demon-special set is Kazali, Legion, and Lord of Typhon. Atheist has its own Storyteller-selected route. The broader controlled-topology set also includes Lil' Monsta and Summoner. If they are insufficient, completed actual characters are randomly selected for conversion in Outsider, then Townsfolk priority, with complete rollback but no pre-start player notification. ## Accepted discard contract

### Ordinary flow

1. Generate three legal cards. Each card independently chooses uniformly among trusted actual character types that are currently legal and have at least one eligible unseen actual candidate, then rolls that actual character's primary archetype and character. With four open types every card is 25% per type; with three it is 33 1/3%; with two it is 50%; with one it is forced. Earlier cards in the same hand do not consume, remove, or reduce a type, and remaining slot counts do not add extra type tickets.
2. After the trusted actual character is chosen, apply any required legal hidden presentation. Drunk and Hermit-Drunk show a Townsfolk, Lunatic and Hermit-Lunatic show a Demon, and Marionette shows a Townsfolk. The shown card may therefore have a different visible type from the rolled actual type, but that presentation never rerolls, reweights, or compensates another card's type result.
3. Inside the rolled actual type, give every eligible actual character four tickets. Halve a character's tickets once for each card already in the current hand with the same actual primary archetype: four tickets with no match, two after one match, and one after two matches. Start fresh for every new three-card, two-card, or one-card hand; earlier discarded hands affect only per-player character history, not archetype weight.
4. The player selects one card or discards the entire three-card hand.
5. After a discard, generate two completely fresh cards using the same process. Categories may repeat; characters already seen by that player may not.
6. The player selects one card or discards the entire two-card hand.
7. Generate one final fresh card. It is the forced choice and has no discard action.
8. Every unselected displayed direct character retires under the existing recycling policy. A discarded hidden actual remains globally available under Jay's accepted hidden-character exception, but that player cannot see the same actual or perceived mask again. Selecting a hidden actual retires it for future drafters.
9. Type and archetype buckets never retire merely because a player discarded cards from them.
10. Before each new turn, after subtracting trusted forced-role reservations, if `remaining Outsiders = remaining unreserved players`, enter face-up Outsider completion for that entire turn. Every 3/2/1 card is a direct visible Outsider; Drunk, Lunatic, Hermit-Drunk, Hermit-Lunatic, and fake Atheist are ineligible.
11. Recompute the completion condition after the player finalizes and all setup modifiers resolve. Never switch presentation modes between that player's three-card, two-card, and one-card rounds.
12. Before generating each three-, two-, or one-card completion hand, count the unused legal direct Outsiders. If that count can fill the whole hand, recycle nothing. If it cannot, keep every unused candidate and draw exactly the shortfall from eligible direct Outsiders discarded by earlier players, then shuffle the complete hand. Never recycle a selected character, a blocked character, or anything already seen by the current player.
13. Before showing the player's first ordinary hand, only its first internally generated card may resolve as Lunatic or Hermit-Lunatic and divert into the special-looking Demon flow. If it does not, exclude those modes from every remaining card in that player's three-, two-, and one-card hands, finish the first ordinary hand, and shuffle its visible positions.
14. A diversion starts its own complete sequential flow with two discards and a forced third card. It can never begin after the player has seen an ordinary hand, so real and hidden special presentation timing remains identical.

### Special-looking Demon flow

1. Precompute the legal perceived special set from Kazali, Legion, and Lord of Typhon. Each offer object already has its trusted actual identity and legality state.
2. Fix the trusted route before showing a card. A winning 10% Demon-special route is guaranteed real. ## Accepted design requirements

- Use a global character catalog with explicit type and archetype metadata. Do not use script order or alphabetical traversal as a randomization source.
- Generate every card by first choosing uniformly among currently open character types, then applying the accepted archetype and character rules inside that type. Allow any legal combination, ordering, and repetition; use within-type soft diversity instead of fixed card slots or hard distinctness rules.
- Close a character type as soon as its trusted remaining need reaches zero. Recompute after every finalized choice and setup modifier, and return that type to the equal lottery if a later modifier creates a new need. Never weight an open type by its number of remaining slots.
- Keep hidden-character presentation as a separate layer after the independent actual-type and actual-character roll. A legal hidden Drunk/Lunatic/Hermit/Marionette result then receives its legal shown character. Never reweight the basic roll, compensate later cards, or stop an otherwise legal same-actual-type combination because the shown mask has a different type.
- Do not use a 50/50 normal-versus-special route roll. Use the accepted fixed whole-game route chance because a special-route win guarantees at least one real special character in the roster.
- Use one fixed 10% game-level Demon-special chance across 5-15 players. Every supported setup has one Demon slot, so player count does not justify a changing route percentage; 10% also keeps this guarded route below the natural `3 / 19` share of the Demon catalog and leaves the ordinary route dominant at 90%.
- Guarantee a real Kazali, Legion, or Lord of Typhon topology whenever the 10% Demon-special route wins. Preserve player uncertainty separately by allowing an eligible ordinary route to give an actual Lunatic/Hermit-Lunatic the identical special-looking flow; do not turn the real special route itself into a hidden fake.
- Give Lunatic and Hermit the same per-character base treatment as every other eligible Outsider. With all 23 Outsiders eligible in a fresh hand, each starts at `1 / 23` before the accepted `4 / 2 / 1` adjustment; the five Outsider archetypes are not five equal aggregate lottery tickets. Hermit-Lunatic uses Hermit's one character ticket and never creates an extra ticket.
- Let any eligible player receive the real special route. Force only that player into the three-character sequential pool, permit exactly two discards, and never repeat a discarded special character.
- Give each character one probability-bearing primary archetype. Record overlapping mechanics only as secondary, non-weighting traits so multi-category characters do not receive extra lottery tickets.
- After the actual-type roll, give every eligible actual character in that type one equal base ticket. Do not give equal probability to differently sized archetype buckets; use the actual character's primary archetype only for the accepted soft-diversity adjustment inside the current hand.
- Implement soft diversity with per-character `4 / 2 / 1` tickets inside the already rolled actual type. A candidate has four tickets when its actual primary archetype has not appeared in the current hand, two after one match, and one after two. Reset for every fresh 3/2/1 hand; never carry archetype weight across discarded hands or into another player's turn.
- Classify hybrid characters by the main player-facing benefit of their ability. Costs, side effects, setup deltas, and legality constraints remain secondary metadata.
- Preserve the ordinary whole-hand 3/2/1 discard shape, but reroll both type and archetype for every fresh card. Do not lock later rounds to a discarded category.
- Remove Atheist's singleton `Special setup` archetype. Keep its route guard separate and classify its player-facing ability under Public action, confirmation, and alternate victory.
- Split Atheist from the random Demon-special pool. Privately let the Storyteller choose `Normal Draft` or `Atheist Draft` before Draft opens; the latter guarantees a real Atheist.
- Force every perceived-Athiest player to see only Atheist, with the same explanation that they may still actually be the Drunk. In non-Atheist starts, only an actual Drunk or Hermit-Drunk may receive that presentation.
- Do not create an Outsider slot for fake Atheist. Roll once at the first legal moment with a remaining Outsider slot and future drafter: immediately at setup when legal, or after the first positive Outsider-count modifier when the initial target was zero.
- Use the accepted 10% game-level fake-Atheist weight, with one roll at the first legal moment and at most one forced fake Atheist per game. If both hidden actuals are legal, give direct Drunk and Hermit-Drunk equal 50/50 weight; if only one is legal, use that one.
- If fake Atheist succeeds, make its reserved player the next private drafter so the hidden Outsider resolves before any forced face-up Outsider completion window.
- When all remaining players must be actual Outsiders, freeze every remaining turn to direct face-up Outsider cards for all 3/2/1 rounds. Do not generate hidden Outsider presentations or fake Atheist inside this completion window.
- Preserve full 3/2/1 depth for every still-required type with strict shortfall-only recycling: reuse nothing when unused legal direct cards of that type can fill the hand; otherwise keep all unused candidates, add only the missing number from eligible earlier-player direct discards, and shuffle. Selected roles, hidden-mask discards, blocked roles, and current-player-seen characters remain hard exclusions. Forced Outsider completion still adds its separate face-up-only presentation rule.
- Never place a hidden-fake special character in an ordinary multi-card UI. All perceived Atheists use the same forced one-card presentation; all real or hidden-fake Kazali, Legion, and Lord of Typhon offers use the same Demon-special Accept/Discard flow.
- Shuffle the displayed card positions after generation so card 1, 2, and 3 do not reveal their internal category route.
- Keep actual and perceived identity metadata separate throughout generation, history, retirement, selection, and final assignment.
- Keep every Storyteller manual override and setup-driven post-draft replacement invisible to affected players before game start. Recalculate and validate trusted actual/presented state privately, leave player-facing Draft history and books unchanged, and reveal only the final presented role through the ordinary game-start role flow.
- For a guaranteed special path, suspend incompatible ordinary Minion and real-Demon offers until the actual choice resolves. A Lunatic mask must not trigger the shown Demon's setup logic.
- Never create a Legion fallback. Once its real route and legal majority are chosen, complete the accepted reservations/conversions or keep the setup blocked until the contract is satisfied.
- Resolve Riot outside the special Draft path and leave its live Minion-to-Riot conversion to the Storyteller.
- For a real Lord of Typhon, retire Minions from player offers but keep them in the Storyteller catalog; block game start until the required neighbouring Minions are manually assigned and validated.
- Keep the controlled routes narrow. Summoner retains its separate no-Demon guard, and Lil' Monsta retains its accepted nested Minion-redraft path rather than joining either `Atheist Draft` or random Demon-special generation.
- Apply hidden masking after the actual legal route is chosen, so normal and special actual topologies can both use the same approved Drunk/Lunatic presentation system without the presentation changing setup.
- For real Lil' Monsta, run a fresh private 3/2/1 offer whose type is always direct Minion and whose archetypes remain randomized. Exclude Summoner, Marionette, and every Minion already in play.
- Extend Grimoire `Change Characters` with a full supported-Demon submenu and Demon-only validation while preserving the existing alignment buttons and current-script character behavior.
- Make that trusted full-Demon submenu available to every Storyteller during every night. Do not automatically prompt or open it at the start of night three. Include Lil' Monsta; selecting it opens a direct-Minion submenu for the same target that excludes Summoner, Marionette, and every Minion already in play, makes that target evil, and records Lil' Monsta as the active Demon separately.
- Represent Lil' Monsta with one game-level Jay-owned active marker rather than assigning role `132` to a player. When the marker becomes active, add Lil' Monsta once to the private server/Storyteller script metadata so Sybillian supplies its night-order and reminder surfaces. Keep each player on their real selected Minion role, leave nightly babysitter handling with the existing Storyteller reminder, and clear the marker during normal game reset.
- Resolve the special-route Outsider target before drafting starts. Use it to filter real special-role eligibility and the legal Legion-count range; never interrupt a player's Kazali selection with a Storyteller dialog.
- Give a normal-route hidden special presentation the same player-visible timing and UI as the real route. Any cover-only special target is a private no-op and never changes ordinary topology; an ordinary game with no special-looking player needs no dummy player-facing step.
- Keep implementation planning and integration Sol-owned to preserve the single accepted contract. Do not start gameplay implementation or `/goal` until Jay accepts the complete implementation and verification plan.
