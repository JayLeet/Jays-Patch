Jay's Patch 1.9.0 Beta 4 is the current cumulative 1.9 beta. It includes every
feature from the earlier 1.9 betas plus the latest fixes and Paint Gun update.

## Main features

- Circular seating for 1-15 players, with layouts that update during setup and
  lock when the game starts.
- A cinematic end-game Grimoire reveal with character and alignment editing,
  cancellation before the first reveal, seat snapshots, role icons, sounds,
  particles and winner reveals.
- Faster Storyteller controls through hotbar tools and server-side dialogs,
  including phase changes, deaths and revives, nominations, timers, seating,
  teleports and Storyteller's Passage.
- A private setup room with base scripts, custom-script import, character-wall
  editing and a choice between Jay's item mode, dialog mode and Sybillian's
  original setup bag.
- Greedy Whalebuffet, where players submit private character preferences in
  parallel, and Draft Buffet, where players privately choose from randomized
  3/2/1 offers.
- Night Chat backported from Sybillian's newer beta for servers using modpack
  1.5.4.

## Character and gameplay tools

- Personal Spy and Widow Grimoire views and guarded live character editing.
- Wraith night visits with Closed, Peek and Eyes Open choices.
- Storyteller controls and notification badges for Fearmonger, Banshee,
  Al-Hadikhia, Cerenovus and Boomdandy actions.
- A Boomdandy TNT-pyre execution leading into a guarded Final Three, while
  keeping Sybillian's normal execution available.
- Banshee voting controls, Storyteller-started Rock Paper Scissors and Slayer
  practice shots.
- A Storyteller queue, votekicks, hand raising, personal night music and the
  full `/botc` command help surface.

## Fun features

- Silly Juice, the Boomdandy party popper, Hot Potato and public d20 rolls.
- King and Vizier entrance items.
- Paint Guns that fire visible snowballs and place temporary, non-destructive
  concrete displays. The normal gun uses the shooter's seat colour; the
  Rainbow Paint Gun creates connected multicolour splashes. Shots can splat
  players with particles and a custom sound, never replace world blocks and
  automatically disappear after 20 seconds.

## Added and fixed through Beta 4

- Greedy's 20 adjusted character abilities now appear in the existing role HUD
  and character tooltips inside Grimoire dialogs without changing the normal
  text in other game modes.
- The Wraith now uses the official ability text globally.
- Personal Grimoire dialogs use normal character names and keep role details in
  their tooltips.
- Greedy setup links players to the adjusted-character reference page.
- Paint Guns now use custom icons, a player-only splat sound with varied pitch,
  brighter light-matched displays, connected surface-aligned splashes, a
  50-block range and a constant 2.5x projectile speed.
- Includes the earlier beta fixes for Buffet setup, Reset Game access, personal
  Grimoire handling, dialog navigation, character wording and generated UI
  consistency.

## Requirements

- Sybillian's Blood on the Clocktower modpack 1.5.4
- Minecraft Java Edition 1.21.10

Back up your existing `world` and `config` folders before installing. This is
an unofficial server-side add-on and is not a standalone server pack.
