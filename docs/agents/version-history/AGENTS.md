# Version History Shelf

Use this shelf when prior work, migration history, command-block state, or
update-preservation context matters.

## Source Routes

- Command-block notes: `docs/project-notes/command-block-notes.md`
- Add-on todo: `docs/project-notes/plugin-todo.md`
- Update preservation: `docs/project-notes/update-preservation.md`
- Human architecture summary: `Jays-Patch/README.md`

## Rules

- Prefer current source files over old notes when they disagree.
- Treat old command-block notes as history unless they describe visible map
  wiring that still exists.
- When behavior moves from world command blocks into Jay's Patch, update notes so
  future sessions do not revive old systems.
- Keep this shelf lightweight until a real slice ledger is needed.

## Verification

- Search for the behavior in current source before relying on history.
- If notes are stale, update or remove the stale claim in the same docs slice.
