## Rules

- Keep root `AGENTS.md` short and durable.
- Put detailed or topic-specific rules in the closest shelf.
- Do not copy unrelated BOTC-Bot Discord or Node.js rules into this Minecraft
  server project.
- Keep docs Codex-focused unless Jay asks for user-facing docs.
- Update references when docs move or filenames change.
- Record durable lessons in `docs/project-notes/lessons-learned.md` after large
  fixes, repeated bugs, or confusing investigations.
- Read `code-health.md` for new-code work, refactors, repeated bugs, broad
  cleanup, complexity, duplication, file-splitting decisions, or maintainability
  concerns.
